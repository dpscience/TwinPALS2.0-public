# Detector catalogue, units and source evidence

The shared SQLite catalogue stores instruments, optical materials, response curves, source references and recorded model assumptions. A missing database is initialized from the bundled factory data. A saved catalogue is opened on subsequent starts. Current entries describe available components; a recorded stream or completed study preserves its own configuration.

At the first start after a catalogue update, Desktop and MCP apply the same versioned additions in one database transaction. An edited factory ID receives new fields and their references. Existing values, curves and explicit switches retain the user's choices, and deleted models stay deleted. When the local photocathode material or QE calibration differs, the Photocathode tab offers the missing film data for review. Unlock the PMT, add the values to the draft, review the curves and references, then save. MCP clients can inspect the same draft with `catalogue_factory_optics` and save it using `catalogue_save` with its expected revision. A new switch in a manually reviewed draft starts off. New factory model IDs are added once in the release that introduces them.

Find comparable devices with catalogue_list, then read the complete record with catalogue_get. For a new PMT, check cathode dimensions and shape, window optics, gain and reference bias, pulse rise, transit time, transit-time spread, response curves, units and source conditions. Rise time, transit time and transit-time spread represent different physical quantities. Distinguish the datasheet's spread convention, such as FWHM, from a model sigma.

The PMT **Photocathode** tab has one optional film section. The 16 factory PMTs enable it. Set `properties.cathode_reflections` to declare usable reflection data. Edit the optical constants in **Curves**. When the catalogue switch is off, the film inputs are optional and are excluded from transport. Supply `properties.cathode_film_nm` plus curves `cathode_n` and `cathode_k` against wavelength in nm or energy in eV. Use dimensionless n > 0 and k ≥ 0 with overlapping spectral coverage. Assign a numbered reference to each field in References. A named local film measurement may omit its URL. The existing QE spectrum remains authoritative. Factory film references describe the material family and wavelength range used for each tube.

For a catalogue change, identify the exact device and variant. Preserve manufacturer citations and state any permitted estimate directly with the property. Supply expected_revision for an update, then read back the saved revision. Cite the entry's own source for a numeric property. The Boras dissertation is the scientific basis of TwinPALS; individual curves have their own provenance.

Example. When a window thickness is an assumption, disclose its value and rationale in the entry and methods. Include a sensitivity comparison if that assumption changes the study conclusion.
