# Module 1 · Detector response

The detector setup determines where gamma energy is deposited and how much scintillation or Cherenkov light reaches each photocathode. Inspect the source and samples, detector positions, scintillator shape and material, wrapping, coupling, optical window, cathode and PMT response for A and B. The minimum crystal energy and Cherenkov switch are recorded with the run.

The transport stream stores accepted photoelectrons and ancestry. Cathode arrival is measured after gamma emission. PMT onset includes the calibrated transit delay and time spread. The analog response sums single-photoelectron kernels using the recorded charge, gain, polarity and effective anode load. The two times in a photoelectron record describe different stages of the same detection.

Na-22 supplies a prompt gamma role and an annihilation-pair role. Co-60 has two cascade roles whose matched records must stay paired. Consult the isotope and role fields before combining files. A zero-response emission and an event producing several accepted photoelectrons have different effects on acquisition efficiency.

Example. To test a faster PMT, keep source, optics and geometry fixed, change the PMT operating point or model supported by the profile, and run transport again. Inspect the accepted photoelectron counts, response timing and saved PMT snapshot before comparing lifetime resolution. A change made to today's catalogue cannot retime an existing transport file.
